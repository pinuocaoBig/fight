# 减脂打卡工具

一个**单文件、零依赖、数据完全本地**的减脂打卡 Web 工具。按「有氧加无氧 + 晚饭减脂餐 + 不吃宵夜 + 周末自由餐」的减脂方法,记录每天的体重、训练与三餐打卡。

## 这是什么

不是又一款热量计算 App,而是一套**可执行的最小减脂方案** + 配套打卡工具。方法本身来自一次从 88 kg 到 78 kg 的真实减脂经历,核心只有四条:

1. **运动:有氧管消耗,无氧管别掉肌肉** —— 有氧以游泳为主(没有泳池就快走、跳绳、爬楼梯),无氧在家只有俯卧撑、仰卧起坐两个动作,隔天一次
2. **饮食:只改两顿,不动午饭** —— 午饭正常吃,晚饭吃减脂餐:主食一拳、蛋白一掌、蔬菜两拳
3. **不吃宵夜** —— 这一条最管用,比任何食谱都直接
4. **周末自由餐** —— 火锅、烧烤照吃,八分饱,吃完照常记录,不因为涨了一公斤就放弃

工具把这套方法变成每天能勾掉的格子,剩下的交给时间。

## 功能一览

### 今日
- **今晚怎么排**:根据你设置的运动时段,自动生成当天的训练时间表
- **今日训练**:有氧 + 无氧任务清单,一键完成、撤销;工作日默认休息,想练随时开启
- **今日饮食**:三条勾掉就行 —— 午饭正常吃 / 晚饭吃减脂餐 / 没吃宵夜
- **今晚这道**:每天自动轮换一道减脂晚餐,可换、可收藏,收藏后只从收藏里轮
- **周末自由餐**:周六周日自动出现,记一顿自由餐不算破戒
- **体重记录**:早上空腹称完随手一记,自动算 BMI、距目标差值

### 食谱
- 内置 **21 道**减脂晚餐,全部基于同一份食材池:6 种优质碳水 + 鸡胸/牛肉 + 5 种蔬菜,做法走少油路线
- 筛选:全部 / 我的收藏 / 15 分钟内 / 汤粥类
- 支持添加自己的食谱,添加后进入每日轮换

### 进度
- 关键指标:累计减重、当前 BMI、最近 7 天训练次数、连续打卡天数
- **体重曲线**:折线图 + 目标体重参考线
- **打卡热力图**:最近 28 天,运动、饮食、自由餐一目了然
- **数据管理**:备份到文件 / 从文件恢复 / 清空全部记录

### 方法
内页完整收录这套减脂方法的来龙去脉,包括为什么只改晚饭、为什么无氧不能省、平台期怎么破。

## 快速开始

不需要安装任何东西,三种用法任选:

**方式一:直接打开**

下载 `减脂打卡工具.html`,双击用浏览器打开即可(推荐 Chrome / Edge / Safari)。

**方式二:GitHub Pages 在线使用**

> 仓库开启 Pages 后,把此链接替换为你的访问地址

**方式三:手机添加到主屏幕**

手机浏览器打开后,通过「添加到主屏幕」当成 App 使用。

## 数据与隐私

- 所有数据(体重、打卡、收藏、设置)**只存在你这台设备的浏览器 localStorage 里**,不联网上传,没有任何账号体系
- 每次操作自动保存(写入主 key + 备份 key 双保险),关掉再打开还在
- 局限:清浏览器缓存、换设备、换浏览器后数据不会跟随 —— 建议每周在「进度 → 数据」点一次**备份到文件**,得到一个 JSON 文件,换设备时「从文件恢复」即可
